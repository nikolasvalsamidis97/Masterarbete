# Atmospheric Exobase Calculation

Computes collision-free exobase heights for the planet templates.

## Scripts

- `Collision_free.py`: builds the exobase table used by atmospheric beta=1 and mass-loss projects.

## Run

From the repository root:

```bash
python Projects/Atmospheric_Exobase_Calculation/Collision_free.py
```

Generated tables and plots are written under `results/`, which is ignored by Git.
