# Fernandez Beta Legacy Test

Keeps the older beta Pictoris comparison test separate from the main Fernandez comparison workflow.

## Scripts

- `Betabictest.py`: legacy comparison/test script.

## Run

From the repository root:

```bash
python Projects/Fernandez_Beta_Legacy_Test/Betabictest.py
```

Generated outputs should be written under `results/` if this script is extended to save files.
