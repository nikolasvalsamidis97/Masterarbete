# Lehtmets Beta Teff Comparison

Generates beta-versus-effective-temperature figures for the Lehtmets comparison.

## Scripts

- `Lehtmets_beta_vs_temp.py`: main comparison plotting script.

## Run

From the repository root:

```bash
python Projects/Lehtmets_Beta_Teff_Comparison/Lehtmets_beta_vs_temp.py
```

Generated plots are written under `results/`, which is ignored by Git.
