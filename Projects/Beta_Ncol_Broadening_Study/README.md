# Beta Ncol Broadening Study

Tests how line broadening changes beta as a function of column density.

## Scripts

- `effect_of_broad.py`: main plot script for the broadening comparison.

## Run

From the repository root:

```bash
python Projects/Beta_Ncol_Broadening_Study/effect_of_broad.py
```

Generated plots are written under `results/`, which is ignored by Git.
