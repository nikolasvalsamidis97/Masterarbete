# Real Mass Loss System Table

Creates the reference table for real systems used in the mass-loss study.

## Scripts

- `real_mass_loss_reference_systems_table.py`: main TeX table generator.

## Run

From the repository root:

```bash
python Projects/Real_Mass_Loss_System_Table/real_mass_loss_reference_systems_table.py
```

Generated tables are written under `results/`, which is ignored by Git.
