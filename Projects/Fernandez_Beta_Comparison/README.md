# Fernandez Beta Comparison

Compares this code's beta values against the Fernandez et al. beta Pictoris reference values.

## Scripts

- `comparison_Fernandez.py`: main comparison plotting script.

## Run

From the repository root:

```bash
python Projects/Fernandez_Beta_Comparison/comparison_Fernandez.py
```

Generated tables and plots are written under `results/`, which is ignored by Git.
