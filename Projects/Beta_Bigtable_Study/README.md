# Beta Bigtable Study

Builds the large beta tables for atoms and molecules over selected stellar templates.

## Scripts

- `Beta_study_bigtable.py`: main table generator.
- `Beta_bigtable_txt_to_tex.py`: converts generated text tables to TeX tables.

## Run

From the repository root:

```bash
python Projects/Beta_Bigtable_Study/Beta_study_bigtable.py
```

Generated outputs are written under `results/`, which is ignored by Git.
