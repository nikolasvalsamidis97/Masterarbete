# Spectra Fernandez Comparison

Plots the BT-NextGen and Fernandez beta Pictoris spectra used by the comparison.

## Scripts

- `spectra_comparison.py`: main spectrum comparison plotting script.

## Run

From the repository root:

```bash
python Projects/Spectra_Fernandez_Comparison/spectra_comparison.py
```

Generated plots are written under `results/`, which is ignored by Git.
