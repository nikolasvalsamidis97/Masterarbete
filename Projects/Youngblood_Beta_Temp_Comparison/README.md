# Youngblood Beta Temp Comparison

Generates beta-versus-temperature plots for the Youngblood comparison.

## Scripts

- `Youngblood_beta_vs_temp.py`: main comparison plotting script.

## Run

From the repository root:

```bash
python Projects/Youngblood_Beta_Temp_Comparison/Youngblood_beta_vs_temp.py
```

Generated plots are written under `results/`, which is ignored by Git.
