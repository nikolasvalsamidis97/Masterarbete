# Photon Pressure Column Plot

Plots photon pressure as a function of column density.

## Scripts

- `photon_pressure_vs_column_density.py`: main plotting script.

## Run

From the repository root:

```bash
python Projects/Photon_Pressure_Column_Plot/photon_pressure_vs_column_density.py
```

Generated plots are written under `results/`, which is ignored by Git.
