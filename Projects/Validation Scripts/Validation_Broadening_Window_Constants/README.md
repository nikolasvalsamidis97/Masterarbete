# Validation Broadening Window Constants

Validates the broadening-window constants used by profile calculations.

## Scripts

- `broadening_window_constants_validation.py`: main validation script.

## Run

From the repository root:

```bash
python "Projects/Validation Scripts/Validation_Broadening_Window_Constants/broadening_window_constants_validation.py"
```

Generated validation outputs are written under `results/`, which is ignored by Git.
