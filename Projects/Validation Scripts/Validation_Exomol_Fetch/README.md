# Validation Exomol Fetch

Validates ExoMol fetching.

## Scripts

- `exomol_test.py`: basic ExoMol fetch validation.

## Run

From the repository root:

```bash
python "Projects/Validation Scripts/Validation_Exomol_Fetch/exomol_test.py"
```

Generated validation outputs are written under `results/`, which is ignored by Git.
