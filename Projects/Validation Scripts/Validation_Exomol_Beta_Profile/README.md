# Validation Exomol Beta Profile

Validates a small beta-profile calculation by reusing the Teff beta=1 module with ExoMol data.

## Scripts

- `exomol_test_2.py`: beta-profile validation script.

## Run

From the repository root:

```bash
python "Projects/Validation Scripts/Validation_Exomol_Beta_Profile/exomol_test_2.py"
```

Generated validation outputs are written under `results/`, which is ignored by Git.
