# Validation SVO Filter

Tests SVO filter scaling for a beta Pictoris-like stellar setup.

## Scripts

- `SvoFilterTest.py`: main SVO filter validation script.

## Run

From the repository root:

```bash
python "Projects/Validation Scripts/Validation_SVO_Filter/SvoFilterTest.py"
```

Generated validation outputs are written under `results/`, which is ignored by Git.
