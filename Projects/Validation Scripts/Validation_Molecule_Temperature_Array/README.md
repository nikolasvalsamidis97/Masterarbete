# Validation Molecule Temperature Array

Regression test for molecule temperature-array handling in photon-pressure calculations.

## Scripts

- `test_molecule_temperature_array.py`: main regression script.

## Run

From the repository root:

```bash
python "Projects/Validation Scripts/Validation_Molecule_Temperature_Array/test_molecule_temperature_array.py"
```

Generated validation outputs are written under `results/`, which is ignored by Git.
