# Validation CO B0 Grid

Validates the CO broadening grid used by the beta bigtable workflow.

## Scripts

- `validate_co_b0_grid.py`: main validation script.

## Run

From the repository root:

```bash
python "Projects/Validation Scripts/Validation_CO_B0_Grid/validate_co_b0_grid.py"
```

Generated validation outputs are written under `results/`, which is ignored by Git.
