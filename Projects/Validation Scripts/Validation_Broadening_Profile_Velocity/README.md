# Validation Broadening Profile Velocity

Validates the velocity grid behavior in broadening-profile calculations.

## Scripts

- `broadening_profile_velocity_validation.py`: main validation script.

## Run

From the repository root:

```bash
python "Projects/Validation Scripts/Validation_Broadening_Profile_Velocity/broadening_profile_velocity_validation.py"
```

Generated validation outputs are written under `results/`, which is ignored by Git.
