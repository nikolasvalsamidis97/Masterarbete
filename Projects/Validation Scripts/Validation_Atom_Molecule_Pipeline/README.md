# Validation Atom Molecule Pipeline

Checks consistency between atom and molecule paths in the photon-pressure pipeline.

## Scripts

- `atom_in_mol_pipeline.py`: main validation and plotting script.

## Run

From the repository root:

```bash
python "Projects/Validation Scripts/Validation_Atom_Molecule_Pipeline/atom_in_mol_pipeline.py"
```

Generated validation outputs are written under `results/`, which is ignored by Git.
