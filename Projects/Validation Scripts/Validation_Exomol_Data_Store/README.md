# Validation Exomol Data Store

Inspects the local ExoMol HDF store layout.

## Scripts

- `gentest.py`: small diagnostic script for reading the local CO ExoMol store.

## Run

From the repository root:

```bash
python "Projects/Validation Scripts/Validation_Exomol_Data_Store/gentest.py"
```

This script expects the ignored `exomol_data/` folder to exist locally.
