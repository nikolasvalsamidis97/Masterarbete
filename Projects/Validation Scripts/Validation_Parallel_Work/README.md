# Validation Parallel Work

Small validation for running the Teff beta=1 workflow through a subprocess.

## Scripts

- `paralell_work_test.py`: subprocess-based parallel-work test script.

## Run

From the repository root:

```bash
python "Projects/Validation Scripts/Validation_Parallel_Work/paralell_work_test.py"
```

Generated validation outputs are written under `results/`, which is ignored by Git.
