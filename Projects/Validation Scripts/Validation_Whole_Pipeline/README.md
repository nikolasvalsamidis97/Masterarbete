# Validation Whole Pipeline

Runs a full atom and molecule photon-pressure pipeline regression.

## Scripts

- `test_for_whole_pipeline.py`: main whole-pipeline validation script.

## Run

From the repository root:

```bash
python "Projects/Validation Scripts/Validation_Whole_Pipeline/test_for_whole_pipeline.py"
```

Generated validation outputs are written under `results/`, which is ignored by Git.
