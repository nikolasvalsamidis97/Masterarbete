# Beta Teff Template Table

Creates thesis tables for beta as a function of stellar effective temperature.

## Scripts

- `Beta_vs_Temp_Table.py`: beta-vs-Teff table generator.

## Run

From the repository root:

```bash
python Projects/Beta_Teff_Template_Table/Beta_vs_Temp_Table.py
```

Generated outputs are written under `results/`, which is ignored by Git.
