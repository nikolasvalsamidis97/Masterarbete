# Beta Tgas Excitation Study

Computes and plots beta as a function of excitation or gas temperature.

## Scripts

- `Beta_Tgas.py`: main beta-vs-excitation table generator.
- `plot_Beta_Tgas.py`: heatmap and plotting helper for the generated tables.

## Run

From the repository root:

```bash
python Projects/Beta_Tgas_Excitation_Study/Beta_Tgas.py
python Projects/Beta_Tgas_Excitation_Study/plot_Beta_Tgas.py
```

Generated tables and plots are written under `results/`, which is ignored by Git.
